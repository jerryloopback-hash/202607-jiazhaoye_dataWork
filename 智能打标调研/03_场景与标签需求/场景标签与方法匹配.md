# 智能打标 · 场景 / 标签 / 方法 匹配表

> 面向「佳兆业文体」用户库，汇报前置调研用。
> 每个场景给出：**业务场景 → 目标标签 → 匹配的智能方法 → 依赖表/依赖层 → 可行性**。
> 场景编号与 PLAN 阶段 3 的候选对齐；`★` 表示优先落地建议。
> 类型标注：**[A] DWS 直算**（不需 ER 层） / **[B] ER 关系**（消费 ER 层关系数据）。

---

## ★ 场景 1〔A〕C 端会员「消费行为偏好分群」（**列为 demo 首选**）

- **业务场景**：把 C 端用户（一起吗 App，`j_member`）按其消费/互动行为分成若干可运营的人群，供精细化运营、个性化营销。
- **目标标签**：「行为偏好簇」——如 `高频游泳型 / 活力订场型 / 活动热衷型 / 积分薅羊毛型 / 沉睡流失型`（取值=簇名，可另附每簇占比）。
- **匹配方法**：**无监督聚类**（K-means/GMM 为主，PCA/UMAP 可视化辅助，HDBSCAN 可自动识别"沉睡/离群"）。
- **依赖表**：`j_member`（主体×静态属性）＋`j_member_order(_detail)`（订单数/金额/type 品类）、`j_order_ticket(_valid)`（票类核销）、`j_platform_activity_person`（活动）、`j_points_records`（积分）、`j_coupon*`（优惠依赖）。
- **类型/分工**：[A] DWS 直算，**不需 ER 层**，只需 DWS 用户主宽表。
- **可行性**：★★★★★ 单源、无标注、表齐全；链路最短，最适合做**首个完整 demo**。

## ★ 场景 2〔A〕会员「流失预警 / 复购预测」—— **（列为场景 B 首选）**

- **业务场景**：预测未来一段时间某用户流失（无任何活动）或复购的概率，用于召回营销 / 留存。
- **目标标签**：「未来 30/60 天流失概率」「高潜复购」等概率型分档标签。
- **匹配方法**：**监督预测（XGBoost）**。**需自造标签 y**：观察期特征 → 标签期是否复购/流失。
- **依赖表**：同场景 1 的 DWS 宽表（需能拆时间窗）；目标由行为时间上自动构造，无需人工标注。
- **类型**：**[A] DWS 直算**（不需 ER 层）。
- **可行性**：★★★★ 需要小心"观察期/标签期"切分防泄漏；与聚类互补，补上有监督这条主线。**已实现为场景 B（详见 04_方案设计与实施/场景B_方案设计与打标模拟.md）**。

## ★ 场景 3〔B〕培训学员「课程/项目兴趣类群 + 相似学员」

- **业务场景**：培训业务（`t_student`）学员 × 课程构成关系网络，据此找"兴趣相近/可互荐课程"的学员群，支撑课程推荐与转介绍。
- **目标标签**：「兴趣类群」（如 游泳培训班型/球类竞技型/少儿体适能型）、「偏好相似学员」（向量近邻）。
- **匹配方法**：**图嵌入**（node2vec，用户×课程二部图）→ 嵌入后再 K-means 或余弦近邻。
- **依赖表/依赖层**：`t_student`×`t_student_course`/`t_syllabus_student`×`t_class`；**此即 ER 层需产出的「学员×课程」关系表**（需与 ER 同事对齐口径）。
- **类型**：**[B] ER 关系**，消费 ER 层产出。
- **可行性**：★★★★ 关系数据充分；完全无监督；依赖 ER 层关系表到位。

## 场景 4〔B〕场馆会员「运动项目偏好 → 相似人群 / 偏好向量」

- **业务场景**：场馆会员（`h_member`）对运动项目（`sport_id`、`m_trade_order_detail.item`）、入闸（`m_enter_gate`）、演出（`theatre_*`）、停车（`p_park_*`）的跨品类偏好画像。
- **目标标签**：「运动偏好向量」「项目偏好 Top」「相似人群」。
- **匹配方法**：**图嵌入（node2vec）/ item2vec / Item-based CF**（用户×项目的多类型交互图）。
- **类型**：**[B] ER 关系**（跨品类关系更复杂，最依赖 ER 层统一"资源"实体)。
- **可行性**：★★★☆ 数据足但关系繁杂、口径统一工作量大（跨 jianengliang/vmdb 两源），作为场景 3 的横向扩展。

## 场景 5〔A〕综合「高价值会员分层」（RFM + 聚类）

- **业务场景**：跨源（会员/储值/消费）给用户打价值标签，支撑会员等级运营。
- **目标标签**：「价值分层」（高价值/潜力/普通/沉睡）——用 最近(R)/频次(F)/金额(M) 替代指标（储值充值、订单金额、入闸频次）+ 聚类或分箱。
- **匹配方法**：**RFM 评分 + 聚类（或分箱规则）**；属"组合套路"。
- **类型**：**[A] DWS 直算**（IF 跨源则需 oneID/ER 实体归一）。
- **可行性**：★★★★ 简单直白；若跨三源做统一用户视图，则依赖 ER 层的**实体归一（oneID）**一环。

## 场景 6〔拓展〕行为序列画像 / 下一行为预测（远期）

- **目标标签**：「序列偏好」「下一行为预测」。
- **匹配方法**：序列模型（LSTM/Transformer）——本期列为远景，因数据质量与部署成本高。
- **可行性**：★★ 延后。

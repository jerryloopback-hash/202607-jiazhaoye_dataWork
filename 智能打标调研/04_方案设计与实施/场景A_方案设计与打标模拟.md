# 场景 A · 方案设计与打标模拟（C 端会员消费行为分群）

> 汇报 + 落地用。**本 demo 定位：跑通完整"特征 → 算法 → 标签"链路，做框架/流程示范，不追求标签质量。**
> 测试库数据质量极差（性别/年龄几乎全空、订单仅 154 个去重用户且大部分对不上 `j_member`），
> 因此**缺失/无效字段用「带固定种子的随机模型」模拟**，保证链路可复现、可评审、可演示。

---

## 1. 业务目标

把 C 端会员（一起吗 App）按其**消费 / 活跃行为**分成若干可运营人群，产出"行为偏好簇"标签。

- **标签名**：`beam_behavior_cluster`
- **取值**：簇命名（如 高频活跃型 / 消费力强型 / 活动互动型 / 沉睡流失型…），另附每簇画像。
- **类型**：[A] DWS 直算，不需 ER 层。

## 2. 数据来源（真实抽取部分）

| 数据 | 来源表（jianengliang 库） | 说明 |
|---|---|---|
| 用户主体 | `j_member` | 9008 用户；`login_num`、`last_login_time` 真实可用 |
| 订单行为 | `j_member_order` | 订单数/金额/品类(type)；仅覆盖少数用户 |
| 活动互动 | `j_platform_activity_person` | 活动参与数 |
| 积分 | `j_points_records` | 积分余额/变动 |

## 3. 数据质量体检（实测，真实值）

- 性别：`sex` 0=8956、1=35、2=17 → **几乎全为"不明"，不可用**。
- 年龄：9007/9008 无效（0 或超界）→ **不可用**。
- 订单主体：`j_member_order.user_id` 仅 154 个去重用户，且仅 44 个能 join 上 `j_member.id` → **订单与会员关系大部分断裂**。
- 可用真实特征：`login_num`(登录次数)、部分有订单用户的订单聚合、活动参与数、积分。

## 4. 方案设计与实现（框架完整版）

### 4.1 特征宽表（8 维，用户×指标）
| 特征 | 真实来源 | 缺失/无效时模拟策略（固定 seed） |
|---|---|---|
| `age` | j_member.age | 截断正态（18~65） |
| `sex` | j_member.sex | 类别分布（男/女/未知） |
| `login_num` | j_member.login_num | **真实**；缺失用泊松 |
| `order_cnt` | j_member_order 聚合 | 幂律长尾模拟（多数低、少数高） |
| `total_spend` | j_member_order.pay_amount 聚合 | 对数正态模拟 |
| `activity_cnt` | j_platform_activity_person | 零膨胀泊松（多数 0） |
| `points_balance` | j_points_records | 对数正态/0 |
| `recency_days` | last_login_time→距今天数 | 指数分布模拟 |

> 模拟均以 `seed` 固定 → **可复现**；每个被模拟的特征在输出里打标，便于评审区分真实/模拟。

### 4.2 清洗变换
- 非法值（负金额/异常大值）裁剪；`log1p` 压缩长尾；`StandardScaler` 标准化（因量纲差异大）。

### 4.3 降维
- PCA 降至 2D（去噪 + 可视化）；用累积解释方差选主成分数。

### 4.4 聚类与选 K
- **K-means**（大样本快、可解释）；遍历 K=2..10，用**轮廓系数(silhouette)+业务可解释性**选 K。

### 4.5 簇画像与命名
- 统计每簇各特征**均值/中位** → 归纳每簇画像 → 命名标签（如 高频活跃/消费强/活动互动/沉睡…）。
- 依据簇中位距（cluster profile）给出描述，保证**标签可解释、业务可用**。

### 4.6 打标与输出
- 输出 `user_id, 簇号, 簇名, 特征` 到 CSV（脱敏，不含手机号/身份证）。
- 输出 PCA 2D 散点图（按簇着色）+ 簇画像表 + 质量报告（真实/模拟占比）。

## 5. 评估（框架演示口径）
- 轮廓系数：衡量簇内紧凑/簇间分离（示例性，非质量判定）。
- 簇画像一致性：人工抽查簇语义是否成立。
- **明示局限**：由模拟数据主导的特征，分群结果不代表真实业务人群；仅证明**链路可运行、方法可落地**。

## 6. 运行
```bash
python scripts/sceneA_clustering_demo.py
```
